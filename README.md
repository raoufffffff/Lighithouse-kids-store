# Lighthouse Toys — المتجر

متجر ألعاب ذكية للأطفال موجّه للآباء والأمهات (Next.js 16 + Tailwind، RTL).

## كيف يعمل (سريع جداً وخفيف)
- **كل الصفحات ثابتة (SSG)**: الصفحة الرئيسية وصفحات المنتجات تُولَّد وقت البناء. زيارة المتجر **لا تستدعي قاعدة البيانات أبداً**.
- لا يُقرأ من قاعدة البيانات إلا عند **التحديث**: كل حفظ في لوحة الإدارة (منتج، توصيل، بيكسل، إعدادات) يستدعي `POST /api/revalidate`، فتُعاد توليد الصفحات ثم تبقى ثابتة. يوجد أيضاً زر «تحديث المتجر» في صفحة إعدادات المتجر بالإدارة.
- نقطة التحديث محمية: لا تقبل إلا توكن مدير مسجّل (يُتحقق منه عبر الدالة `lh_is_admin()` في Supabase)، فلا يوجد سرّ مشترك.
- لا JavaScript تقريباً في الصفحة الرئيسية. صفحة المنتج تحمّل فقط فورم الطلب وزر «اطلب الآن».
- الطلب يُرسل عبر الدالة `lh_place_order` في Supabase، وهي تحسب الأسعار والتوصيل من قاعدة البيانات (لا يمكن التلاعب بها من المتصفح).

## المتغيرات (Vercel → Environment Variables)
| المتغير | الوصف |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | رابط مشروع Supabase |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | المفتاح العام (publishable) |
| `NEXT_PUBLIC_SITE_URL` | (اختياري) رابط المتجر لمعاينات المشاركة |
| `ADMIN_ORIGIN` | (اختياري) رابط لوحة الإدارة لتقييد CORS |

وفي مشروع **الإدارة** أضف `VITE_STORE_URL` = رابط هذا المتجر.

## التشغيل محلياً
```bash
cp .env.example .env.local
npm install
npm run dev
```

## ما يتحكم فيه الأدمن
اسم المتجر والشعار والجملة التعريفية (إعدادات المتجر)، المنتجات وألوانها ومقاساتها وصور صفحة الهبوط (فوق/تحت الوصف)، أسعار التوصيل لـ 58 ولاية، وبيكسل فيسبوك/تيك توك.
